# Posts de Sentido Value (@sergiocortesinvesting)

**Fuente:** datos reales vía Windsor.ai + lista de permalinks entregada por Sergio (2026-09-23). **No inventados.**

- Archivo: `posts-sentido-value.csv` — los **31 posts** entregados (22 jul 2026 → 21 sep 2026), orden cronológico.
  *(Sergio los llamó "últimos 30"; la lista de links contenía 31 y se incluyeron todos.)*
- Campos: `#, fecha, formato, hook_resumen, palabra_clave, likes, comentarios, guardados, compartidos, alcance, visualizaciones, guard_x1000_alcance, engagement_rate_%, promocionado, permalink`.
- `guard_x1000_alcance` = guardados ÷ alcance × 1000 (normaliza guardados por audiencia).
- `engagement_rate_%` = (likes+comentarios+guardados+compartidos) ÷ alcance × 100.
- `promocionado` = "Sí" si visualizaciones > 1.000 (regla de Sergio: >1.000 views = Meta Ads). **En este set: 0 promocionados** → los 31 son orgánicos (máx. 492 views).

## Métricas N/D

- Tema/ángulo/formato interpretados manualmente donde el caption no lo revela. `palabra_clave` "N/D" = el post no traía comando de comentario claro.

## Nota de calidad de datos

- Todos orgánicos: útil para leer rendimiento **orgánico puro**, pero el alcance es bajo (cuenta pequeña, 75–377), así que las diferencias entre posts son de pocas unidades → **muestra chica, conclusiones como hipótesis**.
